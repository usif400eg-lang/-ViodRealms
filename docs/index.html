Installation

Waypoints work fully offline — the dashboard is optional.

1. Build or download

Grab a release JAR, or build from source with Maven:

mvn clean package

On Windows, build-plugin.cmd builds and copies the JAR for you.

2. Install on Paper

# Copy the JAR into your server
cp VoxelPanel-1.0.0.jar server/plugins/

# Start the server once to generate config
# plugins/VoxelPanel/config.yml

3. Configure & register

Set web.url and web.token in plugins/VoxelPanel/config.yml, then start the server. It registers itself and appears online in the panel.

Requirements

  • Paper for Minecraft 1.21.1
  • Java 21+
  • Maven 3.9+ (to build from source)
  • A Firebase project (for the dashboard)

Secure by design

The dashboard never holds the Firebase service account. Access is enforced by Firebase Auth + Realtime Database Security Rules.

🔑

Token authorization

Each server gets a unique id and secret token. The plugin proves it holds a matching token and never writes it back to Firebase.

⏱️

Instant revocation

The plugin live-watches its token. Revoke or rotate it from the panel and syncing stops within seconds — never crashing the server.

🧩

Duplicate detection

A per-boot instance id exposes fake or duplicated connections that reuse the same credentials.

🛡️

Owner-scoped rules

Server metadata is owner-writable only; the auth token is readable solely by its owner, and presence fields are read-only to clients.

🔁

Auto-reconnect

Built on Firebase's realtime channel, the plugin heartbeats and reconnects automatically after network failures.

🙈

Secrets stay local

The Admin service account key lives only on the server and is git-ignored — never committed or shipped to the browser.
