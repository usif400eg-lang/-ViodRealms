Installation

Waypoints work fully offline — the dashboard is optional.

1. Build or download

Grab a release JAR, or build from source with Maven:

mvn clean package

On Windows, build-plugin.cmd builds and copies the JAR for you.

2. Install on Paper

# Copy the JAR into your server
cp ViodRealmsTPU-1.0.0.jar server/plugins/

# Start the server once to generate config
# plugins/ViodRealmsTPU/config.yml

3. Connect (optional)

Use the dashboard wizard to generate config.yml, drop it into plugins/ViodRealmsTPU/, and restart. Done.

Requirements

  • Paper for Minecraft 1.21.1
  • Java 21+
  • Maven 3.9+ (to build from source)
  • A Firebase project (for the dashboard)

Secure by design

The dashboard never holds the Firebase service account. Access is enforced by Auth + Security Rules.

🔑

Token authorization

Each server gets a unique id and secret token. The plugin proves it holds a matching token and never writes it back.

⏱️

Instant revocation

The plugin live-watches its token. Revoke or rotate it and syncing stops within seconds — no server crash.

🧩

Duplicate detection

A per-boot instance id exposes fake or duplicated connections using the same credentials.
